# Librairies Altium
## Les composants R, L et C sont gérés dans Excel
 TEP-AltiumLib-Passives-RLC.xlsx -- fichier Excel pour la gestion de la liste de pièces et des liens PCBlib et SCHlib
 TEP-AltiumLib-Passives-RLC.dbLib -- Liens de la base de données
 TEP-AltiumLib-Passives.pcbLib -- Empreintes PCB des composants passifs
 TEP-AltiumLib-Passives.schLib -- Symboles Schématique des composants passifs
 
## Les autres composants sont gérés dans les fichiers .Lib
### TEP-AltiumLib.PcbLib
    Tous les Empreintes PCB
### TEP-AltiumLib-Connectors.SCHLIB
    Connecteurs TH et SMT
### TEP-AltiumLib-Discretes.SCHLIB
    Composants discrets: Diodes, transistors
### TEP-AltiumLib-ICs.SCHLIB
    Circuits Intégrés
### TEP-AltiumLib-Modules.SCHLIB
    Modules, PCB
### TEP-AltiumLib-Hardware
    Testpoints, Mounting hole et standoff, composants pour Outillage, logo...
### TEP-AltiumLib.SchLib 
    Tous les autres : crystals, oscillateurs, batteries, interrupteurs...
